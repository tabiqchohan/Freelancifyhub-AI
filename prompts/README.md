# Prompts

Prompt templates and system prompts used by the FreelancifyHub AI ecosystem.

Each file is a reusable, versioned prompt or prompt template. Variables are
referenced as `{{variable_name}}` so they can be interpolated at runtime.

Existing files:

- `prompts1` — repository foundation requirements (the project was scaffolded
  from it). Treat it as the originating spec.
- `prompt2` — Freelancify AI Blueprint v1.0 requirements (the master
  architecture document). Implemented in `docs/freelancify-ai-blueprint-v1.0.md`.
- `prompts3` — Product Requirements Document (PRD) requirements (the official
  functional spec). Implemented in `docs/product-requirements-v1.md`.
- `prompts4` — Agent Catalog & Registry v1.0 requirements (the official
  registry of every AI agent). Implemented in `docs/agent-catalog-v1.md`.
- `prompts5` — AG-001 Master Orchestrator engineering specification
  requirements. Implemented in `docs/master-orchestrator-specification-v1.md`.
- `prompts6` — Shared Memory Architecture specification requirements
  (AG-002 implementation contract). Implemented in
  `docs/shared-memory-architecture-v1.md`.
- `prompts7` — Tool Registry Architecture specification requirements
  (AG-004 Tool Manager & Tool Registry implementation contract). Implemented in
  `docs/tool-registry-architecture-v1.md`.
- `prompts8` — Knowledge Base Architecture specification requirements
  (AG-003 Knowledge Manager implementation contract). Implemented in
  `docs/knowledge-base-architecture-v1.md`.
- `prompts9` — Agent Development Kit (ADK) standard requirements. Implemented in
  `docs/agent-development-kit-v1.md`.
