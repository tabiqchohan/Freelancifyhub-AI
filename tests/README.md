# Tests

Test suites for the FreelancifyHub AI ecosystem, run with Vitest.

| Directory            | Scope                                      |
| -------------------- | ------------------------------------------ |
| `tests/unit/`        | Unit tests (pure functions, schemas, libs) |
| `tests/integration/` | Integration tests (reserved)               |
| `tests/e2e/`         | End-to-end tests (reserved)                |

Run with `npm test`, watch with `npm run test:watch`, and measure coverage with
`npm run test:coverage`.
